\begin{abstract}
We evaluate a lightweight text and URL screening system with logistic stacking on
real messages containing embedded links. All inference is local. An untouched grouped
SMS holdout and an independent URL holdout replace earlier non-nested evaluation.
The dataset uses upstream keyword-derived smishing labels, so results measure agreement
with weak supervision rather than independently verified fraud. The interaction model
achieves F1 0.9303 on 2632 paired holdout messages.
No algorithmic novelty, statistical significance, calibrated probability or
sub-4ms endpoint latency is claimed.
\end{abstract}

\section{Data and preprocessing}
The Combined Labeled Smishing Dataset at commit
\texttt{3bf9983df4b187ee9b54a671e4b5bc5f0d48b3fc} contains 84,863 rows.
Its authors assign smishing labels using keyword rules.
Our shared preprocessing retains 73,989 records, including 8,995 real paired messages.
It removes 10,703 duplicate rows and quarantines 45 conflicting normalized groups.
No synthetic pairs are generated. The separate good/bad URL corpus contains 549,346
original rows. Canonical duplicates/conflicts are removed; all SMS hostnames are excluded
before selecting 50,000 external URL examples.

Unicode NFC preserves composed words. Case, whitespace and recognized phone/money/OTP
entities are normalized. All recognized URLs are extracted; scheme and hostname are
normalized while path/query case is retained. This is not complete deobfuscation.
Training and inference use the same saved transformations.

\section{Method and evaluation}
The text pipeline uses sublinear word TF-IDF (1--2 grams, at most 10,000 features)
and balanced Logistic Regression with $C=1$.
The URL pipeline uses 13 standardized lexical/structural features, character TF-IDF
(3--5 grams, at most 1,000 features) and HistGradientBoosting (depth 4, 100 iterations).
The maximum branch score over all URLs is combined with text by
\[
s=100\,\sigma(\beta_0+\beta_1p_t+\beta_2p_u+\beta_3p_tp_u).
\]
Text-only and URL-only inputs use their available trained branch.

Groups connect identical normalized texts and shared hostnames.
The text model uses 59,190 training records; 14,799 SMS are held out before fitting.
The external URL model uses 39,983 training rows and a disjoint 10,017-row hostname holdout.
Five inner grouped folds create text OOF predictions strictly within SMS training.
The external URL estimator has never seen any SMS hostname or SMS label.
The meta-learner uses 6,363 real paired training messages.
The 2,632 paired SMS test messages remain untouched by every training stage.

The deployed bundle preserves these holdout exclusions and records data hashes,
source revision, runtime version, split indices and preprocessing/model fingerprints.
A missing or incompatible bundle returns unavailable, not a safe score.

\section{Product contract and limitations}
Every score uses local trained estimators, including the 30--79 review interval.
Below 30 is low model risk; 80 and above is high model risk.
These are fixed policy thresholds, not calibrated probabilities or proven optima.
The displayed uncertainty is only score-midpoint distance.
No domain whitelist or brand heuristic changes model scores.
Image and dialogue evaluation are unavailable until suitable local models exist.

Keyword-derived label bias limits all conclusions.
Groups use hostnames, not registrable domains or known campaign IDs.
Vietnamese, expert-labelled, temporal and cross-campaign generalization remain untested.
The experiment does not isolate each engineered feature's contribution.
API requests start a Python process; endpoint timing includes imports and model loading.
Earlier claims about cloud call savings and sub-4ms endpoint latency are withdrawn.
The project is an applied baseline using established methods.
