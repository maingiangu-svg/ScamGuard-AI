# PDF font

`NotoSans-Regular.ttf` is bundled locally so exported reports retain Vietnamese
characters without a third-party font request. Source:
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Redistribution license: SIL Open Font License 1.1, preserved in `OFL.txt`.
The application embeds a subset through jsPDF at export time.
